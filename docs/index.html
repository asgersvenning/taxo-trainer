First launch

If your computer shows a warning

The current installers are unsigned. Download them only from this project's GitHub Releases page, and continue only if you expected to install Taxo-Trainer. You do not need to turn off your computer's security settings.

Windows

If the installer is blocked, right-click the downloaded TaxoTrainerSetup.exe, open Properties → General, and select Unblock near the bottom if it appears. Select Apply, then OK, and try again. If Windows then says it protected your PC, choose More info → Run anyway if available and you trust the download.

macOS

Try opening the app once. If macOS blocks it, open System Settings → Privacy & Security and choose Open Anyway for Taxo-Trainer.

Linux

After extracting the archive, open a terminal in the extracted folder and run ./taxo-trainer.

Once it opens

Start with an example

Open Settings & Data to import a GBIF Darwin Core archive. The app also offers GBIF-hosted plant, butterfly, bird, and cetacean examples. Review the linked GBIF terms before importing.
